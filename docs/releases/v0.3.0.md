Sample code, and fixes from using 0.2.0.

- Sample code for every part: tap an LED, RGB LED, piezo or speaker (or a
  button's label), or use Sample code in a part's sheet. It runs as
  pasted: the part's wiring.fs constants, an -init word that sets up the
  clocks, pins and peripheral, words to drive or read the part, and a
  demo. It follows the part's settings (lit while high or low, common
  anode, pull resistor, EXTI edge) and its pin (GPIO, timer channel, ADC,
  DAC). Every part and setting on every pin the app offers was run on the
  emulator with the real firmware
- Adding a part: the app's pin choice, the reason and the resistor come
  first, with Add right below; the other pins are behind a button
- Board: the RGB LED's wires no longer cross, each row is labelled R, G or
  B; the USB-serial box is a slim strip
- Scope: Hold and Trigger keep what is on screen (part of it disappeared
  over time); panning reaches all kept history
- Registers: a Copy button (a long press on the text set off copies
  while scrolling); the run line has its own row
- Numbers use a decimal point in any language
- Emulator: a typed character could be lost now and then (the first one
  of a line, while a timer ran); the MOE message no longer appears while a
  timer is still being set up
